\section{AI Usage Summary}

AI tools (specifically Claude) were used for the following purposes during the course assignment:

\begin{enumerate}
	\item \textbf{\LaTeX citation formatting}: General question about best practices for citing specific tables in \LaTeX documents.
	\item \textbf{Equation transcription}: Assistance in converting handwritten mathematical derivations into \LaTeX code.
	\item \textbf{Conceptual clarification}: Discussion regarding time unit conversions in the \ac{cr3bp} framework.
	\item \textbf{MATLAB app inspection}: General question about accessing code within MATLAB applications.
	\item \textbf{Visualization code generation}: Generation of matplotlib code most of the plots.
\end{enumerate}
